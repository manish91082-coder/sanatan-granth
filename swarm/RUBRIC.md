# RUBRIC: साप्ताहिक meta-audit के प्रश्न

**संस्करण: 0.1-draft** (14 नवंबर 2026)। यह मसौदा है। पहले दो साप्ताहिक audits के बाद मालिक की स्वीकृति से 1.0 बनेगा, और तभी नीचे का audit-calibration set स्थिर होगा। उससे पहले audit-मॉडल नहीं बदलेगा (मास्टर योजना §8 नियम 9)। इस फ़ाइल में बदलाव केवल PR से, मालिक की स्वीकृति पर।

## Drift/canary निगरानी (हर audit में दर्ज करें)

जूरी-सहमति-दर · CONTRADICTED-दर · ID-mismatch-दर · कृत्रिम-canary पकड़-दर (प्रकार-वार) · `pipeline_version` बदलाव। पिछले हफ़्ते से अचानक बदलाव हो तो उस lane पर stop-condition का प्रस्ताव issue में।

## Audit-calibration set

(ख़ाली। पहले दो audits के M3-नमूनों से ~10 items यहाँ आएँगे, मालिक की स्वीकृति से। audit-मॉडल बदले तो पहले इन्हें दोबारा audit करें और सहमति-बहाव AUDIT_LOG में लिखें।)

## हर audit का अंत

1. `audit/weekly/YYYY-Wnn.md` लिखें।
2. `swarm/AUDIT_LOG.jsonl` में एक पंक्ति जोड़ें: `{ts, model_id, effort, session_or_task_id, rubric_version, inputs:{ledger_sha, pr_ids, sample_ids}, findings[], verdict, next_check}`।
3. एक issue खोलें: शीर्षक "साप्ताहिक audit YYYY-Wnn: N RED, N AMBER"।
4. सुधार हों तो अलग `claude/fix-*` PR में। कभी merge नहीं।
