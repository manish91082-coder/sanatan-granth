# Privacy policy: "Sanatan Granth Library" (Google Drive connector)

*Last updated: 16 November 2026*

"Sanatan Granth Library" is a Google OAuth client used by the owner of this repository, and by nobody else, to store this project's own files (source scans, releases, run logs) in the owner's own Google Drive.

- **Who can sign in:** only the project owner. The client is not offered to the public and has no other users.
- **What it can access:** it requests only the `drive.file` scope, so it can see and change only the files and folders that it created itself. It cannot read the rest of the Drive.
- **What it collects:** nothing. It gathers no personal information, runs no analytics, and shares no data with anyone.
- **Where the files go:** they stay in the owner's Google Drive. The access token is kept in the owner's own configuration and is never written to this repository.
- **How to remove access:** the owner can revoke it at any time at <https://myaccount.google.com/permissions>.

Questions: open an issue at <https://github.com/manish91082-coder/sanatan-granth/issues>.

## गोपनीयता नीति (हिंदी)

"Sanatan Granth Library" एक Google OAuth client है, जिसे केवल इस repo के मालिक उपयोग करते हैं, ताकि इस परियोजना की अपनी फ़ाइलें (स्रोत-scans, releases, run-logs) उनके अपने Google Drive में रखी जा सकें।

- **कौन sign in कर सकता है:** केवल परियोजना के मालिक। यह client जनता के लिए नहीं है और इसका कोई दूसरा उपयोगकर्ता नहीं है।
- **पहुँच:** केवल `drive.file` scope। यह वही फ़ाइलें और folders देख और बदल सकता है जो इसने ख़ुद बनाए हों; बाक़ी Drive नहीं पढ़ सकता।
- **क्या इकट्ठा होता है:** कुछ नहीं। कोई निजी जानकारी नहीं ली जाती, कोई analytics नहीं, और किसी से कुछ साझा नहीं होता।
- **फ़ाइलें कहाँ रहती हैं:** मालिक के Google Drive में। access token मालिक की अपनी configuration में रहता है और इस repo में कभी नहीं लिखा जाता।
- **पहुँच हटाना:** मालिक कभी भी <https://myaccount.google.com/permissions> पर इसे हटा सकते हैं।
